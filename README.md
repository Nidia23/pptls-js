# ✂️ Piedra, Papel o Tijera (Rock, Paper, Scissors)

Una implementación web interactiva y responsiva del clásico juego de **Piedra, Papel o Tijera**, desarrollada utilizando JavaScript puro (Vanilla JS). 
El usuario juega en tiempo real contra la computadora, la cual genera sus elecciones de forma aleatoria.

---

## 🚀 ¿A qué responde este proyecto?

Este proyecto fue creado con el objetivo de poner en práctica y consolidar conceptos fundamentales del desarrollo web *Frontend*:
* **Lógica de programación:** Manejo de condicionales y control del flujo del juego.
* **Manipulación del DOM:** Actualización dinámica de la interfaz de usuario según los resultados de cada ronda.
* **Manejo de eventos:** Captura de las acciones del usuario (clicks/elecciones) en tiempo real.
* **Estado de la aplicación:** Control del marcador de puntos entre el jugador y la computadora.

---

## 🛠️ Tecnologías utilizadas

* **JavaScript (ES6+):** Lógica principal del juego, algoritmo de la computadora y manipulación del DOM.
* **HTML5:** Estructura semántica de la interfaz del juego.
* **CSS3:** Estilos visuales, diseño adaptativo (*responsive design*) y transiciones.

---

## 🎮 Características del juego

* 🤖 **Modo vs. Computadora:** La máquina elige sus jugadas de manera completamente aleatoria.
* 📊 **Marcador en vivo:** Registro automático de las victorias del jugador y de la computadora.
* 🔄 **Reinicio:** Opción para resetear la puntuación y comenzar una nueva partida.
* 📱 **Diseño adaptativo:** Funciona adecuadamente tanto en dispositivos móviles como en escritorio.
